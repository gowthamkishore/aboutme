## 📖 Story

Growing up in the 90s, I was the kid who took RC cars apart just to understand how the wireless signal got from the remote to the wheels. By college, I'd graduated to dismantling and rebuilding entire PCs, and fixing whatever household appliance broke down, more out of curiosity than obligation.

Like most Indian households, engineering was already the plan for me. But that same curiosity is what pointed me toward Electronics and Instrumentation Engineering (2010–2014) instead of leaving the choice to chance.

The years right after graduation weren't a straight line. I wrote the AFCAT three times and didn't clear it. I made it through a week of Army selection and came up short there too. Every door I thought I wanted kept closing.

What opened instead was a role in Bangalore as an Application Engineer, building LabVIEW-based software for industrial automation (2014–2015), followed by a move to Chennai as a Project Engineer (2015–2016).

By 2016 I wanted to own what I built instead of executing someone else's roadmap, so I founded Gixtronix Technologies. A decade later, that decision has turned into 100+ systems deployed and partners like ISRO, DRDO, and HAL.

The tools have changed: LabVIEW rigs, industrial systems, a company of my own. But the question is still the same one I started with: **how does this work?**

<summary><b>🧑‍💻 About this repo (run, build, deploy)</b></summary>

This is the source for the portfolio site, built with [Next.js](https://nextjs.org) and statically exported to GitHub Pages at [gowthamkishore.github.io/aboutme](https://gowthamkishore.github.io/aboutme).

**Run locally**

```bash
npm install
npm run dev
```

Open [http://localhost:3000/aboutme](http://localhost:3000/aboutme). The page auto-updates as you edit files under `src/app` and `src/components`.

**Build**

```bash
npm run build
```

`next.config.ts` sets `output: "export"`, so the build produces a fully static site in `out/`, with no server runtime.

**Deploy**

[`.github/workflows/deploy-gh-pages.yml`](.github/workflows/deploy-gh-pages.yml) builds and publishes `out/` on every push to `main`. `basePath: "/aboutme"` matches the repo-scoped Pages URL. The Pages source must be set to **GitHub Actions**.

**Tech stack:** Next.js 16 (App Router, static export) · React 19 · Tailwind CSS 4 · TypeScript · Phosphor Icons
